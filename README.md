# מפתק למנדט — ballot-spikes

A Hebrew scrollytelling explainer: how the votes in the ballot box become 120 Knesset seats.
It covers the 3.25% threshold, the general quota, surplus agreements and Bader-Ofer, and ends with how many
votes your pick was from changing the result.

Stack: SvelteKit (static) · PixiJS (canvas stage) · GSAP ScrollTrigger · Vitest.

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # allocation engine vs. official Knesset 25 result
pnpm build      # → build/ (static, deployable anywhere)
```

## Data

- `data/k25.json` — certified Knesset 25 results (tests use this).
- `data/k26.json` — Knesset 26, generated by `pnpm results`. When it exists, the site uses it; otherwise it falls back to K25.
- `data/k26-lists.json` — **hand-maintained**: ballot letters → list names, eligible voters, surplus agreements.

To refresh Knesset 26 counts:

```sh
pnpm results                                  # fetches https://media26.bechirot.gov.il/files/expb.csv
pnpm results path/to/downloaded/expb.csv      # or from a file downloaded by hand
RESULTS_URL=https://… pnpm results            # or another URL
pnpm data                                     # recompute allocation + sensitivity → src/lib/data/election.json
```

`pnpm build` runs `pnpm data` automatically. Lists under 1% of the vote are grouped into one "others" spike.
That never affects seats.

## Layout

- `src/lib/election/` — pure TS: `allocate.ts` (seat allocation with step log), `sensitivity.ts` (min votes to flip a seat).
- `src/lib/stage/` — Pixi stage. Everything on it is a function of `(step, progress, pick)` and eased toward that target each frame.
- `src/lib/story/timeline.ts` — step names shared by the page and the stage.
- `src/routes/+page.svelte` — all copy, plus the ScrollTrigger wiring.
